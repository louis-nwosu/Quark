Capabilities

Everything an agent needs, nothing it doesn't.

No IDE. No plugin. Just a binary and a terminal.

Multi-Provider

OpenAI, Anthropic Claude, or OpenRouter. Swap with a single flag. Free tier works out of the box.

Agent Loop

A think-act-observe loop with up to 25 rounds of autonomous tool calls per turn. No supervision required.

Read & Write

Surgical file editing with targeted string replacement. Zero context loss during edits.

Code Search

Regex-powered grep and glob matching across your entire codebase in milliseconds.

Shell Execution

Run bash with configurable timeouts. Test, build, deploy without leaving the agent loop.

Session Persistence

Conversations survive restarts. Auto-resume with full history. Pick up where you left off.

Context Compaction

Smart LLM-based summarization when history grows long. Automatic and transparent.

Zero Dependencies

A single Go binary. No runtime, no VM, no npm install. Download and run.

Privacy First

API keys stay local. Zero telemetry. No data leaves your machine except to your chosen LLM.
